# Hi there, I'm Dr. Mohammad Shoaib 👋

I am a **Research Fellow in Energy and Transport Modelling** at University College London (UCL). My research focuses on leveraging complex system simulation methodologies to accelerate Net Zero transitions, optimize hydrogen infrastructure, and advance circular economy supply chains. 

With a background in Industrial Engineering, I specialize in building hybrid simulation frameworks that bridge the gap between economic assessment and real-world policy/operational decision-making.

---

### 🔬 Research Interests & Expertise
* **Systems Modelling:** Hybrid Simulation (Agent-Based Modeling, System Dynamics, Discrete Event Simulation)
* **Decarbonization Sectors:** Maritime & Aviation Transitions, Green Supply Chains, Sustainable Healthcare Infrastructure
* **Advanced Tech Integration:** Combining discrete event simulation frameworks with Agentic AI, Large Language Models (LLMs), and RAG architectures.

### 🛠️ Technical Toolkit
* **Languages & Frameworks:** Python (`salabim`, `pandas`, `numpy`), Java, MATLAB
* **Simulation Platforms:** AnyLogic
* **AI/LLM Frameworks:** LangChain, OpenAI API / Open-source LLM orchestration
* **Typesetting & Documentation:** LaTeX, Markdown

### 🚀 Current Projects
* **Maritime Decarbonization:** Simulating the electrification and transition paths for ferries in the Dover-Calais corridor using Python (`salabim`).
* **Economic Assessment Frameworks:** Developing scalable simulation architectures to model macro-level economic impacts of green infrastructure deployment.
* **Agentic Simulation:** Exploring the integration of LLM-driven agents into traditional system dynamics and discrete event frameworks.
